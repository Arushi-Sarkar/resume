# Arushi Sarkar — Portfolio Website

Personal portfolio and resume site for Arushi Sarkar — Applied AI student at Temasek Polytechnic and Data Engineer Intern at OCBC Bank.

🔗 **Live site:** https://arushi-sarkar.github.io/resume/

## About

A responsive, multi-page portfolio built with plain HTML, CSS, and JavaScript — no frameworks or build tools required.

- **Home** ([index.html](index.html)) — introduction and highlights
- **About** ([about.html](about.html)) — background, skills, and experience
- **Projects** ([projects.html](projects.html)) — featured work in AI, automation, and data engineering
- **Contact** ([contact.html](contact.html)) — ways to get in touch

## Tech Stack

- HTML5 / CSS3 ([css/style.css](css/style.css))
- Vanilla JavaScript ([js/script.js](js/script.js))
- [Font Awesome](https://fontawesome.com/) icons
- [Google Fonts](https://fonts.google.com/) (Inter, Space Grotesk)

## Running Locally

No build step needed — just open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deployment

Deployed via [GitHub Pages](https://pages.github.com/) from the `main` branch.
